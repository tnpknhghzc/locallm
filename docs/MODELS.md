# Модели

Любые `*.gguf`, найденные в папках поиска, классифицируются по имени: содержит `embed`, `e5`, `bge`,
`minilm`, `gte`, `nomic` → эмбеддер, иначе → языковая модель.

| Роль | Модель | Размер | Примечание |
|---|---|---|---|
| LLM (по умолчанию) | Qwen2.5-3B-Instruct Q4_K_M | ~2 ГБ | хороший русский, 8 ГБ RAM |
| LLM (слабые ПК) | Qwen2.5-1.5B-Instruct Q4_K_M | ~1 ГБ | `-profile fast` |
| LLM (16 ГБ, качество) | Qwen2.5-7B-Instruct Q4_K_M | ~4.7 ГБ | на CPU медленно (3–5 ток/с); `-profile quality` |
| Эмбеддинги | Qwen3-Embedding-0.6B Q8_0 | ~0.65 ГБ | сильный русский; на CPU индексация книги в 1500 стр. может занять десятки минут |
| Эмбеддинги (быстрее) | multilingual-e5-small (GGUF) | ~0.13 ГБ | в 10–20 раз быстрее; GGUF не из официального репозитория — сконвертируйте `convert_hf_to_gguf.py` из llama.cpp или возьмите проверенную сборку |

Префиксы запроса/документа (`query: `/`passage: `, инструкция Qwen3) подставляются автоматически по имени файла.
Размерность эмбеддингов определяется из модели; при смене модели векторы пересчитываются сами.

Ссылки в `scripts/fetch-models.sh` указывают на официальные репозитории Qwen; перед релизом проверьте имена файлов.
